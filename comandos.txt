### Comandos a serm utilizados no workshop

## Instalar o projeto inicial

cd ~environment
sam init --name "ws-serverless-patterns" --location "https://ws-assets-prod-iad-r-iad-ed304a55c2ca1aee.s3.us-east-1.amazonaws.com/76bc5278-3f38-46e8-b306-f0bfda551f5a/module2/sam-python/sam-cookiecutter-2023-11-03.zip"



## Vá para o diretório do novo projeto e remova o arquivo samconfig.toml

cd ws-serverless-patterns
rm samconfig.toml


## Vá para o diretório ./users

cd ./users


## Instale o tree

sudo yum -y install tree

tree


### Crie um ambiente virtual para o Python

pip freeze
python -m venv venv
source venv/bin/activate
pip freeze


### Construa o projeto do data store


cd ~/environment/ws-serverless-patterns/users
sam build


### Faça o deploy do data store.

sam deploy --guided --stack-name ws-serverless-patterns-users
